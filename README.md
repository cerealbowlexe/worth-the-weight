# Worth the Weight

Personal lean-bulk tracker. Installed on iPhone from Safari (Share → Add to Home Screen) and opens full screen.

- `index.html`: the app
- `sw.js`: offline cache
- `logs.json`: entries Claude logs from chat, merged into the app on open (see `COACH.md`)

Your data is stored on the device. Export a backup from **Plan → Your data** now and then.
Don't clear Safari website data or delete the home-screen app, or the phone's copy is gone.
